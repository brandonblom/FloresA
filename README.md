# Flores amarillas para Alejandra 🌼

Una carta web para el 21 de septiembre. Funciona como sitio estático: no necesita instalar paquetes ni ejecutar un proceso de compilación.

## Verla en tu computadora

Abre `index.html` en el navegador. También puedes servir esta carpeta con cualquier servidor estático.

## Publicarla en GitHub Pages

1. Sube el contenido de esta carpeta a la raíz de tu repositorio.
2. En GitHub, entra a **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, la rama donde subiste los archivos y la carpeta **/(root)**.
4. Guarda los cambios y espera a que GitHub muestre la URL del sitio.

Si tu repositorio ya tiene Pages configurado, basta con subir estos archivos a la rama y carpeta que usa el despliegue. `index.html` es el punto de entrada.

Para cambiar el texto de la carta, edita los párrafos dentro de `<article class="letter-paper">` en `index.html`.
